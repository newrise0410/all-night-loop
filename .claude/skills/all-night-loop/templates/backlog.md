# BACKLOG

상태: `[ ]` 대기 · `[~]` 진행중 · `[x]` 완료 · `[!]` 막힘 · `[?]` 제안(사람 승인 전)

작성 규칙
- 한 항목 = 한 사이클(= 한 커밋)로 끝낼 수 있는 크기. 크면 하위 항목으로 쪼갠다.
- ID는 재사용하지 않는다 (JOURNAL·커밋 메시지와 대조하기 위해).
- 루프가 발견한 SPEC 밖의 아이디어는 `[?]` 로 적는다. 루프는 `[?]` 를 실행하지 않는다.
  사람이 `[ ]` 로 바꿔야 실행 대상이 된다.
